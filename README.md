# BENZENE!! — ベンゼン環ドンジャラ プロトタイプ

学校公開デモ向けの、ベンゼン環（芳香族化合物）を学びながら遊べるドンジャラ風ハイスコアゲームのWebプロトタイプです。

## 特徴

- **完全ノンスクロール（100vw × 100vh）のモニター向けゲーム画面**
- **8種の官能基**（`CH3`, `OH`, `COOH`, `Cl`, `NH2`, `NO2`, `Br`, `SO3H`）を6頂点のベンゼン環に配置
- **回転・反転（正六角形 $D_6$ 対称群・12パターン）の自動同一判定**（全32種の教科書レベル化合物に対応）
- **「ベン！！」演出 & 3D分子シミュレーション**: 役が成立したら `Space`（本番ではJoy-Conを倒す）で発動。スプリング物理による分子アセンブリ、ドラッグ3D回転、加熱（熱振動）シミュレーションを搭載
- **比較検証スイッチ**: 上部バーから「1枚引き / 3択ドラフト」「6T / 8T / 10T」を切り替え可能

## 遊び方

`index.html` をブラウザ（Chrome / Edge 推奨）でそのまま開くだけで動作します（外部ビルド不要）。

| 操作 | キーボード | マウス |
| :--- | :--- | :--- |
| 頂点（1〜6位）の選択 | `←` `→` または `1`〜`6` | 頂点をクリック |
| 配置 / 上書き交換 | `Enter` / `Z` | 「おく！」ボタン / ダブルクリック |
| パス | `X` | パスボタン |
| Hに戻す（1ターン消費） | `D` / `Backspace` | 「Hにもどす」ボタン |
| 「ベン！！」発動（アガリ） | `Space` | 右下の「ベン！！」ボタン |
| 役一覧（レシピ帳） | `R` | 上部の「役」ボタン |
| （3択ドラフト時）候補切替 | `Q` / `E` | 牌をクリック |
