# ベンジャラ!! — ベンゼン環ドンジャラ プロトタイプ

学校公開デモ向けの、ベンゼン環（芳香族化合物）を学びながら遊べるドンジャラ風ハイスコアゲームのWebプロトタイプです。

---

## はじめかた（導入手順）

### コードの編集・開発に参加する方向け（Gitを使う方法）

手元でコードを修正したり、最新版をすぐに取り込みたい場合はターミナル（コマンドプロンプト）で以下を実行します。

```bash
# 1. リポジトリを手元のPCにコピーする（初回のみ）
git clone https://github.com/rikutoyamada01/benzene-donjara.git

# 2. フォルダに移動する
cd benzene-donjara
```

あとはフォルダ内の `index.html` をブラウザで開けばOKです。
他のメンバーが更新した最新版を取り込みたいときは、フォルダ内で以下を実行してください。

```bash
git pull
```

### 遊びたい人向け

ZIPファイルをGithubのこのリポジトリからダウンロードして、解答します。
その後、フォルダ内の `index.html` をブラウザで開けばOKです。

## 操作方法

| 操作 | キーボード | マウス |
| :--- | :--- | :--- |
| 頂点（1〜6位）の選択 | `←` `→` または `1`〜`6` | 頂点をクリック |
| 配置 / 上書き交換 | `Enter` / `Z` | 「おく！」ボタン / 頂点をダブルクリック |
| パス | `X` | 「パス」ボタン |
| Hに戻す（1ターン消費） | `D` / `Backspace` | 「Hにもどす」ボタン |
| **「ベン！！」発動（アガリ）** | `Space` | 右下の「ベン！！」ボタン |
| 役一覧（レシピ帳）を開く | `R` | 上部の「役」ボタン |
| （3択ドラフト時）候補切替 | `Q` / `E` | 牌をクリック |

### 上部バーのテスト用スイッチ
画面右上のボタンから、ゼミでの検証用にルールを切り替えられます。
- **`🎲 1枚` / `🃏 3択`**: 1枚ランダム引きと、3枚から選ぶドラフト制の切り替え
- **`⏱ 6T`**: ターン数の切り替え（6 / 8 / 10ターン）
- **`📖 役`**: 登録されている全32種の化合物とスコアの一覧
- **`🏆 順位`**: ブラウザ内に保存されたハイスコアの確認
- **`🔊 音`**: 効果音の ON / OFF

---

## うまく動かないときは？

- **音が出ない**: ブラウザの仕様上、ページを開いて最初に1回ボタンをクリック（またはキー入力）すると音が鳴るようになります。右上の `🔊 音` がオンになっているかも確認してください。
- **画面が少しはみ出す**: ブラウザの表示倍率を **100%**（Windowsは `Ctrl + 0`、Macは `Cmd + 0`）に戻してご覧ください。
- **推奨ブラウザ**: **Google Chrome** または **Microsoft Edge** をお使いください（今後追加予定の Joy-Con 接続機能でも Chrome / Edge が必要になります）。

## 現在の実装内容

- **完全ノンスクロール（100vw × 100vh）** のモニター投影向けゲーム画面
- **8種の官能基**（`CH3`, `OH`, `COOH`, `Cl`, `NH2`, `NO2`, `Br`, `SO3H`）を6頂点のベンゼン環に配置
- **回転・反転（計12パターン）の自動同一判定**（全32種の教科書レベル化合物に対応）
- **「ベン！！」演出 & 3D分子シミュレーション**: 役が成立したら `Space`（本番ではJoy-Conを倒す）で発動。スプリング物理による分子アセンブリ、ドラッグでの3D回転、加熱（熱振動）シミュレーションを搭載
