# VS Code おすすめ設定ガイド

このリポジトリでは、コード実装は主に AI に任せ、メンバーは **Markdown（`.md`）でのドキュメント・仕様管理** と **HTML（ゲーム画面）の動作確認** を中心に進めます。  
その作業がラクになる VS Code のおすすめ設定です。

---

## 1. おすすめ拡張機能を一括で入れる（1分）

このリポジトリのフォルダを VS Code で開くと、右下に **「このリポジトリにおすすめの拡張機能をインストールしますか？」** という通知が出ます。  
**「すべてインストール」** を押すだけで、以下の拡張機能がまとめて入ります（通知を閉じてしまった場合は、左の拡張機能アイコン → 検索欄に `@recommended` と入力すると一覧が出ます）。

| 拡張機能 | 何ができるか | このリポジトリで入れる理由 |
| :--- | :--- | :--- |
| **Live Server** | 右下の **`Go Live`** ボタン1個で HTML をブラウザ表示＆自動リロード | ゲーム画面（`index.html`）をすぐ確認でき、将来の Joy-Con（WebHID）接続でも必要な `localhost` 環境をそのまま作れるため |
| **Markdown Preview Enhanced** | 数式や図にも対応した高機能プレビュー | スコア定式化（`docs/score-formula.md`）の数式や仕様書を綺麗に見ながら確認できるため |
| **Markdown All in One** | 箇条書きの自動継続、太字（`Ctrl+B`）などの入力補助 | Word 感覚でストレスなくドキュメントを書けるため |
| **GitHub Pull Requests** | VS Code 内で Issue・PR の確認やコメントができる | ブラウザと行き来せず、ドキュメント編集から PR 作成まで完結できるため |
| **Git Graph** | ブランチの流れを路線図のように表示 | Git に慣れていなくても「今どのブランチにいるか」が一目で分かるため |
| **Japanese Language Pack** | VS Code のメニューを日本語化 | 英語メニューのままだと設定や Git 操作で迷いやすいため |

---

## 2. よく使うショートカット（これだけ覚えればOK）

* **HTML をブラウザで開く**: `index.html` を開いた状態で、VS Code 右下の **`Go Live`** をクリック
* **Markdown を横並びでプレビュー**: `.md` ファイルを開いて **`Ctrl + K` を押したあと `V`**（Mac は `Cmd + K` → `V`）
  * 左に編集画面、右に完成プレビューが並んでリアルタイムに確認できます

---

## 3. 個人の基本設定でオンにしておくと便利なもの

* **自動保存（Auto Save）**: 上部メニュー **`ファイル`** → **`自動保存`** にチェックを入れる
  * 保存し忘れによる「ブラウザに反映されない」「コミットし忘れた」を防げます。

> ※Markdown の長い文章を画面幅で自動折り返しする設定（`editor.wordWrap`）は、`.vscode/settings.json` でこのリポジトリ全体に自動適用済みです。
